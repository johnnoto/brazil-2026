# Apuração Brasil 2026

Live map of Brazil's 2026 presidential runoff (October 25, 2026), built for The Globe in Brief.

The page reads the official results feed of Brazil's electoral court (TSE, resultados.tse.jus.br) directly in the reader's browser and refreshes every 30 seconds. It adds a "tie line" for each state, region and major city: the share Lula would need there for a 50–50 national race, based on the October 4 first round and how each state shifted between rounds in 2022. The method is explained on the page. The page does not call the race.
